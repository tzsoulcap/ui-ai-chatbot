The chatbot widget now includes a toggle button to view and manage chat history!

🔧 Features Added:

  • 📋 History Toggle Button - Click the clipboard icon in the header
  • 📂 Load Previous Chats - Click the folder icon to load a chat
  • 🗑️ Delete Chats - Click the trash icon to delete a chat
  • 🆕 New Chat Button - Start a fresh conversation
  • 📅 Date & Time Display - See when each chat was created
  • 🎯 Active Chat Highlighting - Current chat is highlighted

📖 How to Use:

  1. Open the widget - Click the chat button
  2. Click the 📋 icon - In the header to toggle history view
  3. View your chats - See all previous conversations
  4. Load a chat - Click 📂 to load a specific conversation
  5. Delete a chat - Click 🗑️ to remove a conversation
  6. Start new chat - Click "New Chat" button
