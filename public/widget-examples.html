Chatbot Widget - Multiple Ways to Set User ID

Priority Order: data-attribute → URL params → localStorage → sessionStorage → global variable → meta tag → postMessage → JavaScript API

Method 1: Data Attribute (Highest Priority)

Set userId directly in the script tag:

<script src="chatbot-widget.js" id="chatbot-widget" data-api-url="http://192.168.50.119:5678/webhook" data-user-id="38137"></script>

Method 2: URL Parameters

Add userId to the URL:

https://yoursite.com?userId=38137 https://yoursite.com?user_id=38137 https://yoursite.com?uid=38137

Method 3: localStorage

Store userId in browser's localStorage:

localStorage.setItem('chatbot_user_id', '38137'); localStorage.setItem('user_id', '38137'); localStorage.setItem('uid', '38137');

Method 4: sessionStorage

Store userId in browser's sessionStorage (cleared when tab closes):

sessionStorage.setItem('chatbot_user_id', '38137'); sessionStorage.setItem('user_id', '38137'); sessionStorage.setItem('uid', '38137');

Method 5: Global Variable

Set a global variable before loading the script:

window.CHATBOT_USER_ID = '38137';

Current global variable:

Method 6: Meta Tag

Add a meta tag in the HTML head (already set in this example):

<meta name="chatbot-user-id" content="38137">

Method 7: postMessage API

Send userId via postMessage after widget is loaded:

window.postMessage({type: 'SET_USER_ID', userId: '38137'}, '*');

Or set multiple config options:

window.postMessage({ type: 'SET_CONFIG', config: { userId: '38137', buttonColor: '#ff0000', position: 'left' } }, '*');

Method 8: JavaScript API

Use the exposed ChatbotWidget API:

window.ChatbotWidget.setUserId('38137'); window.ChatbotWidget.setConfig({ userId: '38137', buttonColor: '#ff0000', position: 'left' });
